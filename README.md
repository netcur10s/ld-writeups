# LetsDefend Writeups

LetsDefend puts you in the role of a SOC analyst responding to real alerts rather than
CTF-style challenges. These writeups document my investigation process, triage decisions,
and conclusions written the way findings would be communicated in a professional SOC
environment.

## Investigation Structure

Each writeup follows this format:

- **Alert Info** — Alert name, type, severity, and timestamp
- **Initial Triage** — First impressions and priority assessment
- **Investigation** — Step by step analysis, tools used, and findings
- **IOCs** — Indicators of Compromise identified during investigation
- **Verdict** — True positive or false positive determination with justification
- **Response Actions** — Containment or escalation steps taken
- **Lessons Learned** — Key takeaways and detection improvements
